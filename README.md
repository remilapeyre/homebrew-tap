# Remilapeyre Tap

## How do I install these formulae?

`brew install remilapeyre/tap/<formula>`

Or `brew tap remilapeyre/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "remilapeyre/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
